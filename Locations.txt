1. Flow (fix)
2. Json file (may change)

The app is for collecting annotations from particcipants in experiment in smart house


The flow is fixed,
 but json files contents may change from time to time 
Json files:
scenario.json
locations.json
activities.json
activities_location.json

Flow 
Interface 1 : 
display time  – every page 
display time  – every page with seconds 
display locations options 
action – allow user to click and choose a location
Interface 2: 
display time  – every page 
display time  – every page with seconds 
display location – the one the user choose 
display activities available in that location as options
action – allow user to click and choose an activity

  Interface 3: 
display time  – every page 
display time  – every page with seconds 
display location – the one the user chooses 
display activity – the one the user chooses
display interaction options (solo, collaborative, assistive)
action – allow user to click and choose an interaction

  Interface 4: 
display time  – every page 
display time  – every page with seconds 
display location – the one the user chooses 
display activity – the one the user chooses
display interaction – the one the user chooses
display person options (Person_B, PersonA) , this is the situation if the user is Person_A
action – allow user to click and choose a person


  Interface 4: 
display time  – every page 
display time  – every page with seconds 
display all options 
action – allow user to edit or accept (submit)



Next background database update with current data
After session fininh user can download file saved as csv
Download options : individual or all the people in the session , for example all the 3 people in the session together in one csv file
